# PitchMark — Cricket Score App

Live cricket scoring built with React + Vite.

## Run

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Features

- Set team names, overs, and who bats first
- Ball-by-ball scoring: 0–6, wide, no-ball, wicket
- Auto second innings + target chase
- Match result (runs / wickets / tie)
- Undo last ball within the current innings
